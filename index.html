New in BrainF Simulator?

The program operates on a tape of cells, each holding a value from 0 to 255, and a pointer that moves between them. Each instruction changes the current cell, moves the pointer, or controls repetition.

Instructions

CharacterAction
+Adds 1 to the current cell.
-Subtracts 1 from the current cell.
>Moves the pointer to the right.
<Moves the pointer to the left.
.Prints the current cell as a character.
,Requests a value and stores it in the current cell.
[Jumps to the matching ] if the cell is 0.
]Jumps back to the matching [ if the cell is not 0.
